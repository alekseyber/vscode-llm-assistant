# Сценарии ручного тестирования — Слэш-команды код-действий (P1, v0.9.0)

Фича P1: 6 слэш-команд в чате (`/explain`, `/explain_stepbystep`, `/doc`, `/test`, `/review`, `/improve`).
Каждая инжектирует директивный system-промпт. Работает в режимах «💬 Чат» и «🤖 Агент», НЕ в Plan Mode.

## Подготовка

1. Открыть workspace с любым TypeScript-проектом (например, сам `vscode-llm-assistant`).
2. Открыть в редакторе файл с кодом (например, `src/modes/chat/SlashCommands.ts`), чтобы код попал в авто-контекст.
3. Настроить провайдера с поддержкой function calling (DeepSeek/SiliconFlow) — для проверки agent-режима.
4. Plan Mode OFF (по умолчанию).

**Формат результата:** каждый сценарий — строго PASS/FAIL.
