# Сценарии ручного тестирования — Каталог скилов (v0.9.0)

## Подготовка

1. Открыть workspace с `.llma/skills/` (coder.md с frontmatter)
2. Режим «🤖 Агент»
3. Plan Mode OFF (обычный режим)

---

## SC-1: Агент видит каталог скилов

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Отправить «какие скилы доступны?» | Агент перечисляет скилы из `.llma/skills/` |
| 2 | Проверить debug-лог | System prompt содержит `## Доступные скилы` с таблицей |

**Статус:** ✅

---

## SC-2: Агент читает полный скил

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Отправить «напиши функцию по правилам coder» | Агент вызывает `read_file(.llma/skills/coder.md)` |
| 2 | Проверить ответ | Агент действует по правилам из скила (комментарии на русском и т.д.) |

**Статус:** ✅

---

## SC-3: Структура скила в промте

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Попросить агента «создай скил tester» | Агент создаёт файл в `.llma/skills/` с правильной структурой |
| 2 | Проверить файл | Содержит frontmatter (`name`, `description`), секции `## Описание`, `## Задача`, `## Правила`, `## Запрещено` |

**Статус:** ✅

---

## SC-4: Без скилов — без каталога

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Открыть workspace без `.llma/skills/` | — |
| 2 | Отправить любое сообщение | System prompt НЕ содержит `## Доступные скилы` |
| 3 | Проверить debug-лог | Секция отсутствует |

**Статус:** ✅

---

## SC-5: Frontmatter с description

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Создать `.llma/skills/helper.md` с frontmatter `description: Помощник` | — |
| 2 | Отправить «какие скилы?» | Агент показывает: `helper | Помощник` |

**Статус:** ✅

---

## SC-6: Fallback без frontmatter

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Создать `.llma/skills/legacy.md` без frontmatter (просто текст) | — |
| 2 | Отправить «какие скилы?» | `legacy | <первые 80 символов текста>` |

**Статус:** ✅

---

## SC-7: Вызов скила через /skill (v0.9.0)

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Отправить `/coder напиши функцию генератора случайных чисел` | Агент инжектит содержимое `coder.md` как system-сообщение |
| 2 | Проверить ответ | Функция написана по правилам скила (русские комментарии, английские переменные) |
| 3 | Режим «💬 Чат» — отправить `/coder` | Скил инжектится, работает и в чате |
| 4 | Plan Mode ON — отправить `/coder задача` | `/skill` игнорируется, работает Plan Mode |

**Статус:** ✅
