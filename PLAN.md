# План: Архитектурная унификация v0.8.0

## Цель
Реализовать 5 архитектурных улучшений по итогам обсуждения внутренней логики плагина.

## Этапы

| Этап | Описание | AC | Зависимость |
|------|----------|-----|-------------|
| 1 | AgentWorker — общий ReAct-движок | runAgentLoop вызывает AgentWorker.run() с колбэками | — |
| 2 | Динамические роли в @orchestrate | Сканирование .llma/agents/*.md, порядок по префиксу | 1 |
| 3 | MCP для оркестратора | extraTools в AgentWorker, одно подключение MCP | 2 |
| 4 | Cost tracking — models[] с pricing | string | {name, pricing}, цены из конфига | — |
| 5 | Реальные токены из usage | usage из createWithTools/chatComplete, chars/4 для chat() | — |
| 6 | Итоговая проверка и подготовка к релизу | Тесты, документация, чек-лист релиза | 1-5 |

## Контрольные точки (гейты)

| Gate | Блокирует | Критерий |
|------|-----------|----------|
| G1 | Этап 2 | npm run compile без ошибок |
| G2 | Этап 3 | npm run compile + тесты AgentWorker |
| G3 | Этап 4 | npm run compile |
| G4 | Этап 5 | npm run compile + тесты |
| G5 | Этап 6 | npm run compile + npm test |

## Процесс этапа

1. Реализовать изменения
2. `npm run compile` — убедиться, что без ошибок
3. `npm test` (если этап затрагивает тесты)
4. Самооценка выполнения AC
5. `git add -A && git commit -m "этап N: описание" && git push origin main`
6. Переход к следующему этапу
