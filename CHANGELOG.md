# Changelog

## 0.13.0 (2026-08-23)

### Редизайн панели чата (P0)

- **Сайдбар сессий** — выезжающий дровер слева со списком диалогов: автозаголовок, превью, timestamp; поиск, избранное, группировка «Сегодня»
- **Toolbar с overflow-меню (⋮)** — data-driven реестр действий; «Удалить все сессии» кнопкой в UI
- **Activity-feed агента** — tool-calls как дружелюбные шаги с иконками («Чтение файла», «Запись файла»…) вместо сырого JSON; после завершения — свёрнутый трейс «🔧 Выполнено N шагов ▾»
- **Input-toolbar с тумблерами** — Ask / Agent / План / Субагенты в строке ввода
- **Группировка tool-шагов по воркерам** в экспорте/копии сессии (`### 01-architect`, `### 02-coder`…)

### Autocomplete — починен ghost text

- **Async-провайдер** — LLM-запрос перенесён в `provideInlineCompletionItems` (раньше подсказка ставилась после запроса VS Code и не перечитывалась → ghost text не появлялся)
- **Отключение thinking** для deepseek-моделей (`thinking: {type:'disabled'}`) — reasoning съедал `maxTokens`, оставляя `content` пустым
- **Фолбэк провайдера/модели** — `getDefault()` → первый настроенный провайдер; модель → первая из списка
- Настройка **`llmAssistant.disableThinking`** — отключение reasoning в чате/агенте/edit

### Исправления

- Пустой код-блок в подтверждении `run_terminal` (команда проброшена в `content`)
- Трейс агента и маркер «Запрос отменён» переживают переключение сессий
- История: одиночный клик — открыть, двойной — детали в оверлей-дровере
- Hover кнопки «Остановить» (текстовая кнопка, не иконка 28×28)
- Двойная нумерация заголовков воркеров в экспорте (`01-01-architect` → `01-architect`)
- Финализация стрима плана: `done` перед `reflectReport` (не «в работе» после завершения)

### Документация

- README: 7 скриншотов в `media/`, актуальные цифры (449 mocked / 22 E2E / 41 spec), настройка `disableThinking`
- Спека `thinking.md`

### Тесты

- **449 юнит-тестов** (mocked) + **22 E2E** в реальном VS Code
- CI: spec-validate → lint → unit → e2e + SDD consistency check

## 0.12.0 (2026-08-22)

### Session-log — источник правды (F1)

- **Сессии в append-only логе** (`SessionLog`, `workspaceState`): каждое сообщение, tool-вызов и результат персистятся — история переживает перезапуск VS Code
- **Копирование/экспорт из лога** (не из DOM): 📋 «Копировать сессию в буфер» + 📥 «Экспорт в Markdown» + команда «Экспортировать сессию» (save-диалог) — полная транскрипция с tool-шагами (`🔧 read_file`, `write_file`, `run_terminal`, …)
- **Fork** — команда «Скопировать сессию (fork)»
- **Удаление** — «Удалить все сессии» с подтверждением
- **Summary + обрезка** — при переполнении контекста старые сообщения сжимаются в «Краткое содержание» и обрезаются из лога (переживает перезапуск)

### Исправления

- **Отмена (⏹️) в оркестраторе** — распознавание `APIUserAbortError` (OpenAI SDK, `name='Error'`) через `isAbortError()` вместо `name === 'AbortError'`
- **Оркестратор: tool-шаги в лог** (F1 5a) — воркеры пишут `tool/call`+`tool/result` через `onEvent`+`sessionId`; экспорт оркестратор-сессий стал полным
- **Воркер без финального ответа** — помечается `⚠️` (не `✅`), статус «Лимит» в истории (`limitExceeded`)
- **Индикатор токенов** — реальный `maxContextTokens` из настроек (не хардкод 4096) + восстановление после переключения сессии
- **Лимит итераций оркестратора** 10 → 20 (тесно coder'у при рефакторинге)
- **README** — добавлен полный список палитровых команд

### Тесты

- **401 юнит-тест** + E2E в реальном VS Code
- CI: spec-validate → lint → unit → e2e + SDD consistency check

## 0.10.0 (2026-08-20)

### Новые возможности

- **Слэш-команды код-действий:** `/explain`, `/doc`, `/test`, `/review`, `/improve` (+ `/explain_stepbystep`) — по выделенному коду
- **Автокомплит слэш-команд:** попап при вводе `/` или `@` — встроенные команды + скилы из `.llma/skills/` + `@orchestrate`
- **Сессионная маршрутизация:** результаты идут в сессию, где стартовал процесс (не в активную); параллельные процессы с per-session `AbortController`
- **Ход выполнения агента:** структурированные сворачиваемые шаги по тулам (`toolActivity`)
- **git-diff в подтверждении `write_file`:** LCS-диф с счётчиком `+N −M`
- **История со старта:** запись появляется сразу (`running`), обновляется по завершении + индикатор «в работе»

### Исправления

- Plan Mode: результат (план/имплементация/рефлексия) **персистится в сессию** — не теряется при переключении чата или очистке истории
- Кнопка «Имплементировать» шлёт **исходную** `sessionId` (не текущий чат)
- Устранена двойная запись в историю Plan Mode (сироты «в работе»)
- `signal` передаётся напрямую в `handlePlanMode` (гонка abort)
- Синтаксическая подсветка кода (`.hljs-*` CSS + без вложенных спанов, лик `class="hljs-string"`)
- Экспорт сессии: переносы строк (`<br>`) и ```-фенсы для кода
- `/doc` `/test` в agent-режиме принудительно пишут файл (флаг `writes` + `⚠️`-директива против текста от DeepSeek)
- Сброс стрим-состояния при переключении сессии (зависший курсор)
- `computeDiff('','')` — пустой диф (было 1 пустая строка)
