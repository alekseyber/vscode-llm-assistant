# Release Notes — v0.10.0

## ⚡ Слэш-команды код-действий

- `/explain`, `/doc`, `/test`, `/review`, `/improve` — выдели код и вызови команду прямо в чате
- Автокомплит при вводе `/` или `@` — встроенные команды + твои скилы из `.llma/skills/` + `@orchestrate`

## 🧵 Сессии и параллельные процессы

- Результаты идут **в ту сессию, где стартовал процесс** — не в активную
- Параллельные запуски в разных сессиях (независимая отмена каждого)
- Двойной клик по строке истории → переход в нужный чат
- Индикатор «в работе» при возврате в сессию с активным процессом

## 📋 Plan Mode — надёжность

- Результат (план → имплементация → рефлексия) **сохраняется в сессию** — не теряется при переключении чата
- Кнопка «✅ Имплементировать» работает в исходной сессии, даже после переключения чатов
- Без дублей в истории запусков

## 🔧 Ход выполнения и подтверждения

- Структурированные сворачиваемые шаги агента (что делает каждый инструмент)
- git-diff в окне подтверждения записи файла: зелёные `+`, красные `−`, счётчик `+N −M`

## 🐛 Исправления

- Синтаксическая подсветка кода в чате (Dark+)
- Экспорт сессии: корректные переносы строк и ```-блоки для кода
- `/doc` `/test` в agent-режиме реально пишут файл (а не отвечают текстом)
- Сброс «зависшего» курсора при переключении сессии

## ✅ Тесты

- **324 юнит-теста** + **18 E2E-тестов** (реальный VS Code)
- CI: spec-validate → lint → unit → e2e
