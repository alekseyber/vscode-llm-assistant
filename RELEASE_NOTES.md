# Release Notes — v0.8.21

## 🆕 Новые инструменты

- **ask_user** — уточняющие вопросы через QuickPick / модальные окна / InputBox
  - Авто-определение Да/Нет по ключевым словам (нужно, надо, стоит…)
  - Ответы с пометкой `[ВОПРОС ЗАКРЫТ]` — запрет на повтор
  - Принудительный вызов при «спроси», «уточни», «предложи варианты»
- **web_fetch** — чтение веб-страниц (HTML→текст, ≤15000 символов, CSS-селектор)
  - Поддержка JSON-эндпоинтов (сырой текст)
  - Таймаут 15 сек, обработка HTTP-ошибок

## 🏗 Архитектура

- **ModelEntry:** расширенный формат `models: (string | {name, pricing})[]` — цены в конфиге
- **calculateCost():** единая функция с fallback-таблицей и пользовательскими ценами
- **Реальные токены:** `usage.prompt_tokens/completion_tokens` из API, chars/4 как fallback
- **Общий ReAct-движок:** `AgentWorker` для чат-агента и оркестратора

## 🤝 Multi-Agent (MA-6 + MA-7)

- **delegate_to_agent:** делегирование подзадач между агентами
- **@orchestrate:** динамические роли из `.llma/agents/*.md`, порядок по префиксу
- **Cost tracking:** стоимость каждого воркера, сводка в оркестраторе, запись в историю
- **MCP:** инструменты доступны чат-агенту и оркестратору

## 🎨 UI

- **Индикатор токенов** в шапке чата (токены + стоимость + прогресс-бар)
- **Стоимость в истории:** каждая запись с токенами, $ и длительностью
- **Сводка оркестрации:** токены и стоимость в чате
- **Удаление сессий:** последняя сессия удаляется с автосозданием новой

## 🔧 Инфраструктура

- **SDD:** 30 spec-файлов (100% покрытие), валидатор, pre-commit hook, CI
- **9 инструментов агента:** ask_user, read_file, write_file, replace_in_file, list_files, search_files, run_terminal, delegate_to_agent, web_fetch
- **Allow-list:** фильтрация инструментов через `.vscode/llm-assistant.json`
