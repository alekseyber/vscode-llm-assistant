# Release Notes — v0.13.0

## 🎨 Редизайн панели чата

- **Сайдбар сессий** слева: список диалогов с автозаголовком и превью, поиск, избранное, группировка «Сегодня»
- **Toolbar ⋮** — «Удалить все сессии» и прочие действия в одном меню
- **Агент как activity-feed** — дружелюбные шаги («Чтение файла», «Запись файла») вместо сырого JSON + свёрнутый трейс после завершения
- **Тумблеры режимов** в строке ввода: Ask / Agent / План / Субагенты
- **Экспорт с группировкой по воркерам** — шаги сгруппированы под заголовком роли

## ⚡ Autocomplete починен

- Ghost text снова появляется (async-провайдер + отключение thinking у reasoning-моделей deepseek)
- Фолбэк провайдера/модели, если дефолтные не настроены
- Настройка `llmAssistant.disableThinking` — отключить размышления в чате/агенте/edit

## 🔧 Исправления

- Пустой код-блок в подтверждении команды терминала
- Трейс агента и «Запрос отменён» переживают переключение сессий
- История: одиночный клик — открыть, двойной — детали
- Двойная нумерация воркеров в экспорте
- План-режим не «висит в работе» после завершения

## ✅ Тесты

- **449 юнит-тестов** + **22 E2E** в реальном VS Code
- CI: spec-validate → lint → unit → e2e

## 🗂 Сессии: полный жизненный цикл (v0.12.0)

- Сессии хранятся в append-only логе — история переживает перезапуск VS Code
- 📋 «Копировать сессию в буфер» и 📥 «Экспорт в Markdown» — полная транскрипция с tool-шагами (что агент читал, писал, запускал)
- Команда «Экспортировать сессию» — сохранение `.md` через системный диалог
- «Скопировать сессию (fork)» и «Удалить все сессии»
- Длинные диалоги автоматически сжимаются: «Краткое содержание» + обрезка старых сообщений

## 🔧 Исправления

- Отмена ⏹️ в оркестраторе больше не падает с ошибкой «Request was aborted»
- Tool-шаги оркестратора видны в экспорте (раньше — только итоговые ответы воркеров)
- Воркер без финального ответа помечается ⚠️ и «Лимит» в истории (не «Успех»)
- Индикатор токенов показывает реальный лимит из настроек, а не 4096

## ✅ Тесты

- **401 юнит-тест** + E2E в реальном VS Code
- CI: spec-validate → lint → unit → e2e

- Команда «LLM Assistant: Review File» — ревью активного файла или выделения

- Отчёт: стиль / безопасность / корректность / оптимизация, замечания по приоритету (🔴 критично / 🟠 важно / 🟡 мелко)
