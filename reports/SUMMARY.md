## Принятые решения

| Решение | Выбор |
|---------|-------|
| Авторизация публикации | **Entra ID + Managed Identity** (не PAT, т.к. глобальные PAT отключены с 01.12.2026) |
| UI чата | **Vanilla JS** (WebView, без React) |
| Autocomplete | **InlineCompletionItem** (стандартный VS Code API) |
| Apply (парсинг инструментов) | **function calling API** (OpenAI-compatible) |
| Apply (цикл) | **ReAct** (итеративный) |
| Хранение сессий | **VS Code Memento** (workspaceState) |
| Выполнение задач | **Durable cronjob** (чистый контекст, report в чат) |
| Git | **HTTPS** (SSH не работает в Docker) |
| Комментарии | **Русский** язык |
| Права файлов | **chmod 644 / 755** |
