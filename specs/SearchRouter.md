## Назначение

Решает, каким путём искать (точный ripgrep или лексический индекс) и склеивает выдачу.
Модель по-прежнему видит один инструмент `search_files`: выбор бэкенда — деталь реализации,
а не новая возможность в контракте.

## Интерфейс

### `classifyQuery(query: string): 'exact' | 'fuzzy'`

| Вход | Тип | Описание |
|------|-----|----------|
| query | string | Запрос модели или пользователя |

`exact` — regex-спецсимволы, идентификаторы (`camelCase`, `snake_case`, точка/слэш в пути),
одно слово без пробелов. `fuzzy` — фраза естественного языка из нескольких слов.

### `needsMerge(fuzzyHits, minHits = 3): boolean`

`true`, если лексическая выдача слишком бедна, чтобы отдавать только её.

### `mergeHits(exact, fuzzy): MergedHit[]`

Точные совпадения сверху, затем лексические, дубли по пути схлопываются; порядок внутри групп
сохраняется. У каждой строки есть `source: 'exact' | 'fuzzy'` — по нему строится выдача.

## Контракты

| Ситуация | Поведение |
|----------|-----------|
| Запрос — идентификатор (`calculateCost`, `PROMPT_EVAL_COUNT`) | `exact`: индекс не спрашивается |
| Запрос с regex-символами (`foo(`, `^export`, `.*`) | `exact` |
| Пустой запрос | `exact` (прежнее поведение) |
| Лексическая выдача ≥ 3 попаданий | отдаётся только индекс, с пометкой «лексический индекс» |
| Лексическая выдача < 3 | склейка с точными совпадениями, дубли по пути убраны |
| Индекс недоступен (нет провайдера) | поведение прежнее, без изменений в выдаче |
| Вопрос без слов после стоп-слов | FTS вернёт пусто → вызывающий код отдаёт точную выдачу |

## Детали реализации

**Почему идентификаторы не идут в FTS.** Стеммер и разбиение по регистру превращают
`calculateCost` в набор слов (`calculate cost calculatecost`), и BM25 выдаёт шум: файлы, где
эти слова встречаются по отдельности. Точный путь на идентификаторах сильнее.

**Порог 3.** Замер стенда (P8): при сыром NL-запросе точный путь даёт 0/15 попаданий,
лексический — 4–8/15. Одиночное попадание индекса недостаточно, чтобы отбросить точную выдачу,
поэтому при < 3 результаты склеиваются.

## Связи

- **Использует:** ничего (чистые функции)
- **Используется:** `ToolDefinitions.search_files` (S3), `SearchIndex`/`IndexService`
- **Не меняет:** контракт и формат ответа `search_files`
