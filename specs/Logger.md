## Назначение

Утилита логирования. Обёртка над `console.log/warn/error` с префиксом `[LLM Assistant]`.

## Интерфейс

- `log(msg)` — информационное сообщение
- `warn(msg)` — предупреждение (жёлтым в Output Channel)
- `error(msg)` — ошибка

## Контракты

| Ситуация | Поведение |
|----------|-----------|
| Любое сообщение | Префикс `[LLM Assistant]` |
| console.warn | Видно жёлтым в VS Code Output Channel |

## Связи

- **Используется:** всеми компонентами через `console.log/warn/error`

## Детали реализации

- **Префикс:** `[LLM Assistant]` во всех сообщениях
- **Методы:** `log()`, `warn()`, `error()` — обёртки над console

## Тесты

Прямых тестов нет. Утилита-обёртка над console — тестируется косвенно через все остальные тесты.
