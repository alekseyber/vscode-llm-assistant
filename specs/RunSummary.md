## Назначение

Честная сводка по фактическим изменениям файлов за прогон агента. Страхует от случая, когда модель отвечает «Готово, заменил», не вызвав ни одного инструмента записи (воспроизведено 08.11.2026 на промте с незакрытой кавычкой и локальной 8B-моделью).

## Интерфейс

### `WRITE_TOOLS: ReadonlySet<string>`

Инструменты, которые пишут в файлы: `write_file`, `patch_file`, `replace_in_file`.

### `countFileChanges(steps) → number`

Считает шаги `tool_result` с инструментом из `WRITE_TOOLS`, у которых результат не начинается с признака ошибки/отказа (`ошибка`, `отклонена`, `error`).

### `fileChangesSummary(steps) → string`

- `📝 Изменено файлов: N` при N > 0;
- `📝 Файлы не изменялись` при N = 0, пустом или отсутствующем списке шагов.

## Контракты

| Ситуация | Поведение |
|----------|-----------|
| Успешный `write_file` | Считается изменением (SUM-1) |
| Успешный `patch_file` | Считается изменением (SUM-1) |
| `read_file`, `search_files` | Не считаются |
| «Операция отклонена пользователем» | Не считается (SUM-3) |
| Ошибка инструмента | Не считается (SUM-3) |
| Прогон без инструментов | `📝 Файлы не изменялись` (SUM-2) |

## Связи

| Компонент | Связь |
|-----------|-------|
| AgentWorker | Источник шагов `tool_result` с `toolName`/`toolResult` |
| AgentController | Источник шагов `tool_result` с `tool`/`result` (маппинг в `startApplyMode`) |
| ChatViewProvider | Добавляет сводку к финальному ответу в чате |
| registerCommands | Пишет сводку в Output Channel в apply-режиме |

## Точки вызова

- `ChatViewProvider.handleAgentMessage` — строка добавляется к финальному ответу в чате и в историю диалога;
- `registerCommands.startApplyMode` — строка пишется в Output Channel «LLM Assistant — Агент».
