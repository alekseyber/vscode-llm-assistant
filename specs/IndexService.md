## Назначение

Подключает локальный индекс к расширению: поднимает хранилище в `globalStorage`, наполняет индекс
в фоне, отдаёт выдачу инструменту `search_files` через провайдер и держит индекс актуальным
через watcher. Любая проблема — поиск продолжает работать прежним путём (ripgrep).

## Интерфейс

### `IndexService.start(context, onDebug): Promise<IndexService | undefined>`

`undefined` — индекс недоступен (нет рабочего пространства, WASM не загрузился, хранилище не
открылось). Активация не ждёт полной сборки: она идёт в фоне.

### `rebuild(): Promise<void>`

Полная пересборка (команда «LLM Assistant: Пересобрать индекс поиска», массовые изменения файлов).

### `info(): { files: number; ready: boolean }`

Статистика для команды и диагностики.

### `dispose(): void`

Flush на диск, отключение провайдера индекса, освобождение watcher и таймеров.
Вызывается из `deactivate()` — это единственный гарантированный момент сохранения индекса.

## Контракты

| Ситуация | Поведение |
|----------|-----------|
| Рабочее пространство не открыто | `start()` → `undefined`, поиск как раньше |
| SQLite/WASM не загрузился | `undefined`, одна debug-строка, без тостов |
| Первый запуск (индекс пуст) | фоновая полная сборка, до её конца поиск идёт точным путём |
| Повторный запуск | сверка (`reconcile`) вместо полной сборки |
| Изменение файла | watcher → debounce 500 мс → переиндексация одного файла |
| Удаление файла | удаление строки из индекса |
| Больше 2000 изменений за минуту | фоновая полная пересборка вместо поштучных обновлений |
| `deactivate()` | `flush`, отключение провайдера, закрытие БД |
| Команда пересборки без индекса | предупреждение «индекс недоступен», без падения |

## Детали реализации

**Путь индекса.** `<globalStorage>/index/<sha1(путь корня).slice(0,16)>.sqlite` — вне рабочего
пространства, чтобы не мусорить в чужом репозитории и не попадать в git.

**Загрузка sqlite-wasm.** Пакет ESM-only; импорт идёт через `new Function('return import(...)')`,
чтобы TypeScript не превратил его в `require` (на ESM падает). Упаковка WASM в VSIX — этап S5.

**Обход.** `workspace.findFiles('**/*', exclude)` уже отбрасывает `node_modules`/`dist`/`.git`/`out`,
поэтому в память не попадает весь репозиторий (замечание ревью S2).

**Watcher.** Один watcher на всё рабочее пространство, события склеиваются по пути (одна правка
часто даёт несколько событий). Переполнение окна изменений уводит в полную пересборку.

## Тесты

Косвенное покрытие: `searchRouter.test.ts` (`IDX-9`, `IDX-21`) — провайдер индекса в инструменте.
Прямых юнитов нет: сервис — проводка VS Code API (watcher, `globalStorage`), проверяется e2e-смоуком
активации и ручным прогоном на реальном репозитории (S5).

## Связи

- **Использует:** `SearchIndexStore`, `SearchIndexer`, `ToolDefinitions.setIndexSearchProvider`
