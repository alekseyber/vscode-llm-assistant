## Назначение

Деньги пользователя: прогноз стоимости до запроса, лимит бюджета сессии и авто-выбор модели
по сложности задачи. Никакой новой функциональности агента — только «сколько это будет стоить»
и «не пора ли остановиться».

## Интерфейс

### `isComplexTask(input): { complex: boolean; reason: string }`

Правила (явные, проверяемые): режим `agent`, Plan Mode, контекст > 6 000 токенов,
текст > 1 500 знаков, наличие маркера из списка (`рефактор`, `спроект`, `архитектур`,
`оптимиз`, `почему`, `объясни`, `разбер`, `тест`, `баг`, `ревью`, `миграц`).

### `chooseModel(input, fallbackModel): RouteDecision`

Работает только если `routing.auto = true` **и** заданы `routing.simpleModel` и
`routing.complexModel`. Иначе возвращает `fallbackModel` с `auto: false`.
Явный выбор пользователя обрабатывает вызывающая сторона (`routing.overrideChosen`).

### `estimateRequestCost(contextTokens, maxTokens, model, pricingMap): CostEstimate`

Вход — фактический размер контекста, выход — `maxTokens × 0.3` (ответ редко упирается в потолок).
Локальные модели дают `0`: цены берутся из `pricingMap` менеджера, где они обнулены.

### `checkBudget(state, estimateUsd, warnPercent = 80): BudgetVerdict`

`off` при `limitUsd <= 0`; `exceed` с `totalUsd`/`overUsd`; `warn` при достижении порога; иначе `ok`.

## Контракты

- Чистые функции: состояние — только настройки и переданные аргументы. Единственное состояние
  в UI-слое — множество сессий, по которым уже предупредили.
- Молчаливой блокировки нет: превышение лимита — всегда вопрос с числами.
- Прогноз — оценка: факт пишется в историю после ответа (реальные токены с 0.14.71).

## Связи

- `ChatViewProvider` — единственный потребитель: перед запросом вызывает `chooseModel`,
  `estimateRequestCost`, `checkBudget`.
- `ProviderManager.pricingMap` — цены моделей; локальные модели там с нулями.
- `RunHistoryStore` — источник фактического расхода сессии (`sessionId` + `cost`).
- `types.calculateCost` — единая формула стоимости, чтобы прогноз и факт считались одинаково.

## AC

| ID | Критерий | Статус |
|----|----------|--------|
| MR-1 | Короткий вопрос + обе модели заданы → простая модель | ✅ |
| MR-2 | Агентский режим → сложная модель, причина «агентский режим» | ✅ |
| MR-3 | Маркеры сложности и длинный контекст распознаются | ✅ |
| MR-4 | Маршрутизация выключена или модели пустые → прежняя модель | ✅ |
| MR-5 | Локальная модель: прогноз стоимости 0, вход из контекста | ✅ |
| MR-6 | `budget.sessionLimitUsd = 0` → проверка выключена | ✅ |
| MR-7 | Прогноз выводит за лимит → `exceed` с перерасходом | ✅ |
| MR-8 | 80% лимита → `warn` | ✅ |
| MR-9 | В пределах лимита → `ok` | ✅ |
| MR-10 | В чате: превышение лимита + отказ → `provider.chat` не вызван, прогон `cancelled` | ✅ |
